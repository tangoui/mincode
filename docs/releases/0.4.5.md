**新增与改进**

- 外部 Agent 可以使用 MinCode 的能力：在 MinCode 终端里运行的 Claude Code、Codex 等 Agent，可通过 `mincode tool` 命令或 MCP 调用终端、数据库、SSH/SFTP、HTTP、浏览器、笔记、设置、概览以及 MinCode AI 会话等工具，并用 `mincode pane split/send/read/wait` 开分屏派任务、等待并读取结果。MinCode 外部的程序需要在设置中打开"允许外部 Agent 使用 MinCode 全部能力"后才能连接。外部调用不弹审批，高危 SQL 仍会弹出确认。
- 退出 MinCode 时，终端分屏里正在运行的程序（如 `pnpm dev`、`claude`）会被记住，下次打开时在原目录自动重新运行；空闲的分屏只恢复为空终端，含密码、令牌的命令不会保存。
- 终端、数据库、HTTP、SSH/Docker 日志和笔记里新增"交给 AI"：选中内容、最近一条命令的输出、查询报错、响应和日志可以一键带进 AI 输入框，确认后再发送。
- MinCode AI 自动读取项目根目录的 `AGENTS.md`、`CLAUDE.md` 和 `.mincode/rules.md`；本地 Agent 会话中输入 `/` 可选用 Agent 提供的命令。
- MinCode 在后台时，AI 完成、需要确认、等待回答或出错会发送系统通知，点击即可回到对应会话。
- AI 回复中提到的本地文件会变成可点击的链接，回复末尾显示文件卡片：图片带缩略图（包括 `file://` 写法的本地图片），其他文件按类型显示图标。

**问题修复**

- AI 会话在后台完成后，在 AI 面板中点击、滚动或输入即视为已读，通知中心里对应的 AI 通知也会一并标为已读。
- 取消系统文件对话框时不再弹出 `tango: canceled` 错误提示。

**New and improved**

- External agents can use MinCode's capabilities. Agents such as Claude Code and Codex running in a MinCode terminal can call terminal, database, SSH/SFTP, HTTP, browser, notes, settings, overview and MinCode AI conversation tools through the `mincode tool` command or MCP, and use `mincode pane split/send/read/wait` to open panes, hand off tasks, wait for them and read the results. Programs outside MinCode can connect after you turn on "Allow external agents to use all of MinCode" in Settings. External calls skip approval, but high-risk SQL still asks for confirmation.
- When you quit MinCode, the programs running in terminal panes (such as `pnpm dev` or `claude`) are remembered and restarted in the same directory next time. Idle panes reopen as empty terminals, and commands containing passwords or tokens are not saved.
- "Send to AI" in terminals, databases, HTTP, SSH/Docker logs and notes brings a selection, the latest command output, a query error, a response or logs into the AI composer for you to review before sending.
- MinCode AI reads `AGENTS.md`, `CLAUDE.md` and `.mincode/rules.md` at the project root. Type `/` in a local agent conversation to use the agent's commands.
- While MinCode is in the background, a system notification tells you when the AI finishes, needs approval, waits for an answer or fails. Click it to return to the conversation.
- Local files mentioned in AI replies become clickable links, and file cards appear below the reply: images show thumbnails (including local images written as `file://` URLs), and other files show type icons.

**Fixes**

- After an AI conversation finishes in the background, clicking, scrolling or typing in the AI panel marks it read, together with its notifications in the notification center.
- Canceling a system file dialog no longer shows a `tango: canceled` error.
