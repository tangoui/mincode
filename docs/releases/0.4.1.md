**新增平台**
- Windows ARM64 安装包。
- Linux ARM64 版本。
- Linux 新增 AppImage、deb、rpm 安装包（x64 与 ARM64），原有 tar.gz 保留。

**更新**
- 通过 tar.gz、macOS 或 Windows 安装包安装的，可在应用内直接下载并重启更新。
- 通过 AppImage、deb、rpm 安装的，检查更新时会提示新版本，并可打开 GitHub Releases 下载新安装包。

**其他**
- 清理已不再使用的内部代码，程序更精简。
